# Induction line-heating inverse-design data

This repository is being prepared for the manuscript **“Generative inverse design of induction line-heating processes for steel plates from three-dimensional displacement fields.”**

## Current status

**No research dataset has been deposited here yet.** This repository URL must not be presented as a location where the paper's supporting data can currently be accessed.

The manuscript's current data availability statement says that the datasets generated and analysed during the study are available from the corresponding author on reasonable request. Any public release of data here is subject to the authors' approval and a check of sharing rights.

## Intended contents

If approved for release, this repository may contain documented, authentic examples of:

- Initial steel-plate point clouds and plate geometry;
- Heating-line process parameters;
- Three-dimensional displacement fields generated by finite-element simulations;
- Corresponding data definitions, units, and instructions for interpreting the files.

The scope of any released subset will be stated explicitly. A small example subset must not be described as the complete dataset.

## Before citing this repository as a data location

The authors will upload the approved data, document the files and access conditions, and update the manuscript's data availability statement to match the actual contents. This repository does not currently have a dataset DOI.
